# LehaSTR — fan/blog landing

Одностраничный адаптивный сайт-портфолио о YouTube/Twitch-блогере **LehaSTR (Lehastroff)**.

## Стек

- React 19
- TypeScript
- Vite
- Lucide React
- чистый CSS + адаптивная вёрстка

## Запуск

```bash
npm install
npm run dev
```

Сайт будет доступен на `http://localhost:8087`.

## Production-сборка

```bash
npm run build
npm run preview
```

Готовые файлы появятся в `dist/`.
